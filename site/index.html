Back up your Yoto cards

YotoLib saves the audio, cover art, and track list of the Yoto cards you own to a library on your computer. It keeps a zip copy of each card, and can copy the whole library to Google Drive. Free and open source.

What YotoLib does

Keep a copy of the cards your family listens to, so a lost or damaged card does not mean lost stories.

Saves the whole card

Each card is stored in its own folder with its audio tracks, cover art, track icons, and a card.json with the title, author, and chapters.

Plays in the browser

Browse and search the library by title, author, or category, and play any track with the built-in audio player.

Keeps a spare copy

A dated zip of every card goes to a separate backup folder, with a recovery list of each card's link so you can download it again.

Backs up to Google Drive

Sign in with Google from the Cloud backup page and copy the library to a Drive folder. Cards that have not changed are skipped.

Runs where you want

A desktop app for Windows, macOS, and Linux, a Docker image for amd64 and arm64, and Kubernetes manifests for a home server.

Stays on your network

The library stays on your computer or server. YotoLib only connects to Yoto to download cards, and to Google when you back up.

How it works

Back up a card in three steps.

  1. Get the card's link. Hold the card to your phone with an NFC reader app such as NXP TagInfo, and copy the yoto.io link it shows.
  2. Paste it into YotoLib. Add one or more links on the Add cards page and confirm that you own the cards.
  3. Browse and back up. The cards appear in your library, with a zip copy in the backup folder and, if you choose, in Google Drive.

Install

Choose the way that suits you. Every option is free.

Desktop app

Download the app for Windows, macOS, or Linux. No Python install is needed. Start it and it opens in your browser.

Docker

Run the image and open http://localhost:8765.

docker run -p 8765:8765 \
  -v yotolib-data:/data \
  ghcr.io/jodachecallan/yotolib

Kubernetes

Deploy with Kustomize from the repository. The Kubernetes guide covers the overlay, Ingress, and storage.

Questions

Which Yoto cards can I back up?

Cards you legally own, or cards you have permission to keep a copy of. YotoLib needs the card's yoto.io link, which you can read from the card with an NFC app on your phone.

Does it need a Yoto account or a Yoto player?

No. YotoLib works from the card's link. You do not sign in to Yoto.

Where are my files stored?

In a library folder and a backup folder that you choose. With Google Drive backup turned on, zip copies are also uploaded to a Drive folder that YotoLib creates. YotoLib can only see the files it created in your Drive.

Can I run it on a home server or Raspberry Pi?

Yes. The Docker image runs on amd64 and arm64, and the repository includes Kubernetes manifests with a NetworkPolicy and a hardened pod spec.

Is it free?

Yes. YotoLib is open source under the MIT licence. The code is on GitHub.
